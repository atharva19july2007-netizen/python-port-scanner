# Python TCP Port Scanner

A simple TCP port scanner built using Python's socket library.

## Features

- Scans TCP ports from 1 to 7777
- Resolves hostnames to IP addresses
- Detects open ports
- Handles connection and hostname errors
- Supports graceful termination using Ctrl+C

## Requirements

- Python 3

## Usage

Run:

```bash
python scanner.py <target>
